# AI 家庭智能体 · Prompt 模板包

> 3 个家庭 AI 助手，每个都有完整的系统提示词和示例知识库，复制粘贴就能用。
> 这是《AI 家庭智能体搭建实战营》（2 小时手机版 / 2 天版）的课后资料包，课程框架一并开源。

**Family AI Agents** — three ready-to-paste system prompts with sample knowledge bases, for parents who want AI to help with communication, homework coaching, and growth planning. Chinese only for now.

---

## 这是什么

课上讲的 prompt 都是片段，知识库也只给了模板，没有填好的示范。这个模板包把最后一步补齐：**每个 Agent 都配一套完整 prompt 和一份填好的示例知识库**，可以直接粘进扣子（Coze）、智谱清言等平台使用。

拿过来照着做就行，不用临场发挥。

## 三个 Agent 一览

| | ① 亲子沟通翻译官 | ② 家庭学习教练 | ③ 成长规划师 |
|---|---|---|---|
| **管什么** | 关系 | 能力 | 方向 |
| **对应什么时刻** | 孩子关门不说话 | 孩子作业看不懂 | 申请季很慌 |
| **一句话** | 让你的话被听进去 | 不直接给答案的家教 | 把零散的经历串成主线 |
| **谁在用** | 你用（孩子不知道） | 孩子用（你定规则） | 你们一起用 |
| **多久见效** | 当晚 | 一周 | 一个季度 |
| **知识库重点** | 孩子说明书 | 错题本 + 教材大纲 | 成长流水账 |

## 15 分钟跑通第一个

1. 用浏览器打开 [`web/家长版-一键复制.html`](web/家长版-一键复制.html)，找到你想先做的 Agent。
2. 点「复制 Prompt」，粘进扣子的「人设与回复逻辑」栏。用智谱清言、豆包等平台的话，粘进「系统提示词」或「角色设定」。
3. 复制「示例知识库」，存成 `.txt`，上传到平台的知识库。
4. 按文档里的「工作流配置」搭好节点。新手可以先跳过这步，有人设和知识库就能用八成。
5. 用示例问题试一遍，看看输出是什么样。
6. 把示例知识库里的「A001」换成你家孩子的信息。

> **铁律**：AI 管流程，你管温度。Agent 做得再好，你不去跟孩子说话，就是零。

**不想注册平台？** 打开 [`web/翻译官-可对话版.html`](web/翻译官-可对话版.html)，填上自己的 DeepSeek（或其他兼容 OpenAI 接口的）API Key，就能直接和「亲子沟通翻译官」对话。

- Key 只存在你浏览器的 localStorage 里，请求直接发给你填写的接口地址，不经过任何第三方服务器。
- 建议用设了额度上限的 Key。公用电脑用完后，记得清除浏览器数据。

## 示范对象：A001（虚构）

三个 Agent 的示例知识库都用同一个**虚构**的孩子「A001」。这样你能看到：同一份家庭档案，怎么喂出三个侧重点不同的 AI 育儿助手。

| 维度 | 内容 |
|---|---|
| **基本档案** | 男，15 岁，10 年级，IB 体系（MYP 末年，明年进 DP），上海某 IB 学校。强项：数学、计算机；弱项：英文写作、人文学科 |
| **性格与行为** | 一点就着，话多，吃软不吃硬。压力大时会关门、摔东西、沉默三天。被认可「有想法」时最开心（不是被夸成绩好） |
| **沟通规则** | 禁语三句：「你看看人家 XXX」「我花这么多钱送你读国际学校」「随你便，我管不了你了」。安全话题：游戏设计、AI 工具、科幻电影。最佳沟通时段：晚 9 点后，他洗完澡出来倒水时 |
| **历史冲突** | 上周末打游戏超时两小时 → 妈妈说「你看看人家」→ 摔门，三天不说话 → 妈妈把道歉纸条塞进门缝 → 第四天他出来说「你别那样说话」 |
| **高光时刻** | 上周用 AI 做了个 2D 游戏原型，眼睛发亮，给妈妈讲了一晚上游戏机制 |
| **活动履历** | 模联、编程社（副社长）、钢琴八级、社区志愿者、AMC10、自学 Blender 3D 建模 |
| **家长侧写** | 妈妈，外企中层，焦虑 IB 成绩和大学申请，口头禅「你怎么又在玩手机」，晚上 11 点累了的时候最容易失控 |

> 这份档案会分别喂出三份侧重点不同的知识库。换成你家孩子的信息就行。

## 方法论速查

**CMRL：写人设**

| 字母 | 含义 | 问自己 |
|---|---|---|
| **C** | Character 角色 | 你是谁？ |
| **M** | Mission 任务 | 你干什么？ |
| **R** | Requirements 要求 | 怎么干？ |
| **L** | Limitations 限制 | 什么不能干？ |

**BISCO：做设计**

| 字母 | 含义 | 问自己 |
|---|---|---|
| **B** | Background 场景 | 你家什么情况？ |
| **I** | Input 输入 | 用户怎么给你信息？ |
| **S** | System 系统 | 人设 + 知识库 + 工作流 + 插件 |
| **C** | Output 输出 | 你输出什么格式？ |
| **O** | Optimize 优化 | 用完怎么让它越来越准？ |

**家庭效果 = 认知 × 工具 × 陪伴**

这是乘法，任何一项为零，结果就是零：

- 认知为零：学完还是偷偷装监控，工具变成新的监控手段。
- 工具为零：道理都懂，从没动手做过一个，焦虑翻倍。
- 陪伴为零：Agent 做得很漂亮，孩子一次没用过，因为你从没跟他好好聊过。

## 使用边界

- 这些 Agent 是沟通和学习的辅助工具，**不能替代专业心理咨询或医疗建议**。孩子有持续情绪问题、自伤风险时，请找专业人士。
- 孩子的真实信息属于隐私。只上传到你信任的平台；不要把填好真实信息的知识库公开分享，也不要提交到公开仓库。本仓库的 `.gitignore` 已经忽略 `private/` 目录，可以把自己的版本放在那里。
- 学习教练的设计原则是「不直接给答案」。请和孩子一起定好使用规则。
