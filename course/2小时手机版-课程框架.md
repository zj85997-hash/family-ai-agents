**🔑 本页比喻**：打客服电话 vs 请了三年的住家阿姨

| 项目 | 内容 |
|------|------|
| **标题** | 一个记不住你家孩子的AI，不配叫"家教" |
| **左栏（聊天机器人）** | ❌ 你问，它答，问完就忘<br>今天问"孩子叛逆怎么办"，它给你一篇公众号；明天再问，还是同一篇<br>**类比：打客服电话**——每次都要从头解释一遍你是谁 |
| **右栏（Agent）** | ✅ 它记得：孩子叫什么、读几年级、什么脾气、上周为什么摔门<br>你说"他又那样了"，它知道"那样"是哪样<br>**类比：请了三年的住家阿姨**——你一个眼神她就懂 |
| **底部公式（简化）** | **Agent = 🧠 大脑 + 📚 记忆**<br>大脑（它聪不聪明）：平台已经帮你配好了，**你不用管**<br>记忆（它懂不懂你家）：你喂给它，**这是你唯一的护城河** |
| **设计** | 暖瓷白背景。左右两栏细线分隔，中间大号"→"。左栏灰调，右栏墨蓝调。底部公式墨蓝底通栏+白字，四个字改为两个部件 |

**🎤 讲师讲稿：**

> 很多家长现在已经在用AI了——打开一个AI软件，问一句"孩子叛逆期怎么办"。
>
> 它给你一段特别正确、特别没用的话：要理解、要倾听、要给空间。你关掉。明天再问，它还是那段话。
>
> **这不叫Agent，这叫查资料。** 就像打客服电话：每次接电话的都是新人，你每次都要从头讲一遍你是谁，讲完他给你个标准答案，挂了。下次打，重来。
>
> Agent不一样。Agent像**你家请了三年的阿姨**。你进门说一句"今天不太顺"，她就知道该给你倒杯茶，别问了。因为她认识你。
>
> 我们要造的Agent，是这样的：它知道你家孩子叫什么、读几年级、什么脾气、上周三为什么摔了门。你打字进去："他又那样了。"它回你："是不是又是关于游戏时间的？上次你们是因为周日下午的两小时吵的，那次你先提高了音量。这次要不要换个开场？"
>
> **这就是Agent和聊天机器人的区别——它记住了你。**
>
> 怎么做到的？记住屏幕下面这个公式，只需要两个词：
>
> **大脑 + 记忆。**
>
> 大脑，就是它聪不聪明——**今天用的平台已经帮你配好了，你完全不用管。** 就像请家教不用管他哪个大学毕业的。
>
> 记忆，就是它懂不懂你家——**这一步只能你来。** 而且我告诉你：大脑人人都能用一样的，**只有"你家孩子长什么样"这件事，全世界只有你知道。**
>
> 所以今天这堂课，技术部分只占三分之一。剩下三分之二，是教你**把你自己写进去**。

| 项目 | 内容 |
|------|------|

>
> **想象你今天新请了一位阿姨，第一天上门。你会跟她说什么？**
>
> **C，角色。** 你不会说"你负责干活"。你会说"你主要负责做饭和陪孩子写作业"。

>
> **L，限制。** 什么不能碰？"不评判家长。不用心理学术语。不给医疗建议。**不承诺照做一定管用。**"这一条是保险丝。AI最爱拍胸脯说"照做孩子一定会改变"，你回去一试没用，更绝望。所以要提前把它的嘴堵上。
>
> 【手机技巧】这几个长句子，别一个字一个字敲——**用键盘上的麦克风，语音输入**，按住说就行。你今天一天都用得上这个技巧。
>

### 第10页 · BISCO三问（2天版P18压缩为三问）

**页面骨架**：行动路径页——三问卡片
**核心观点**：造任何家庭Agent，先回答三个问题
**🔑 本页比喻**：盖房子先画图纸
**📎 沿用中阶课方法论**：BISCO 压缩为 B / I / C 三问（S与O并入口头提示）

| 项目 | 内容 |
|------|------|
| **标题** | 设计任何一个家庭AI，先问三个问题 |
| **问1 · 场景（B）** | **哪件事让你家最头疼？**<br>❌ "我想要个学习助手"<br>✅ "每周三晚上物理作业，必吵一次，每次1小时。我想把这一小时降到十分钟"<br>**B写得越具体，AI越好造** |
| **问2 · 输入（I）** | **用的时候，你给它什么？**<br>打一段话？拍一张题？粘一段聊天记录？<br>**如果每次用都要写500字，你三天就放弃了** |
| **问3 · 输出（C）** | **你想拿到什么？格式写死。**<br>"只给我三句话，每句不超过20个字，我要能直接念出来"<br>不写死，它给你三千字分析——你半夜站在孩子门口，看得完吗？ |
| **口头一句（S+O合并）** | 怎么教会它（人设+说明书）+ 用完记一行反馈——这两个今天都会带你做，完整方法论在资料包 |
| **案例速览** | 亲子沟通翻译官：**B**=一说话就吵架 → **I**=输入"我想说…"或"他说…" → **C**=四段式输出（见下页） |
| **设计** | 暖瓷白背景。三个问句做成三张横排大卡片，问号用超大琥珀橙。底部案例速览用一条墨蓝窄条 |

**🎤 讲师讲稿：**

> 刚才你造出来的AI，回得有点傻。为什么？因为它**不知道你是谁**。
>
> 把它调聪明，方法就是三个问题。这套方法我给企业老板上课也用，一模一样——**设计企业客服和设计家庭教育AI，底层逻辑完全相同。** 所以你学的是一套通用能力，回去用在工作上一样好使。
>
> **第一个问题：这个AI到底解决什么事？**
>
> 要具体到让人尴尬的程度。"我想要个学习助手"——等于没说。"**每周三晚上物理作业必吵一次，每次一小时，我想把这一小时降到十分钟**"——这才叫清楚。**第一个问题答得好，后面全都顺。**
>
> **第二个问题：用的时候，你给它什么？**
>
> 打一段话？拍张照片？如果每次都要写500字，你坚持不了三天。**输入越简单，你才会真的用。**
>
> **第三个问题：你想拿到什么？**
>
> 这一条一定要**写死格式**。不写死，它给你三千字分析，你半夜十一点站在孩子门口，看得完吗？写死："**只给我三句话，每句不超过20个字，我要能直接念出来。**"
>
> 就这三个问题。现在我们把答案填进你刚才那个AI里。
